Upload directly to GitHub

On your computer, open PowerShell in the ComicArchiver project and run:

python -m reusable.local_comic_uploader

The authenticated local editor opens automatically. Select PDFs of any file size, choose chapter boundaries and start the resumable upload. Keep the terminal running. Existing imported comics can still be edited or deleted here.

Manage imported comics

1. Select and order files

Select several images, PDFs, or both through your computer’s native picker. Files are initially sorted naturally by name. Use the order controls before generating chapters.

When splitting each PDF, the selected chapter count applies independently to every PDF. Pages stay in order and are divided as evenly as possible; any extra pages go into the earliest chapters. Image-only files still use the pages/images per chapter setting. Review and adjust the boundaries in the preview. The local Python renderer normalizes supported images to PNG; animated files use the first frame. Large pages may be downscaled to fit the 12 MiB image ceiling. PDF pages are rendered one at a time, and original PDFs never leave your machine. Up to 2,000 pages per comic; input PDF byte size is unrestricted. Unsupported formats pause rather than being skipped.

2. Edit comics & chapters

Edit metadata, reorder chapters and pages, split a chapter at any page, or merge adjacent chapters. Changes to a published comic become visible only after Save.
