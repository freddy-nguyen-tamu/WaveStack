Manage imported comics

If an upload was interrupted, use Recover / edit draft here rather than starting another import. Existing GitHub pages can be reused without uploading again.

1. Select and order files

Select several images, PDFs, or both. Files are initially sorted naturally by name. Use the order controls before generating chapters.

When splitting each PDF, the selected chapter count applies independently to every PDF. Pages stay in order and are divided as evenly as possible; any extra pages go into the earliest chapters. Image-only files still use the pages/images per chapter setting. Review and adjust the boundaries in the preview. Standalone images use high-quality JPEG for JPEG sources and PNG for other sources by default. Choose lossless PNG to avoid additional JPEG compression. PDF pages default to high-quality JPEG (94%); select lossless PNG if needed. Keep this tab open during uploads; the progress bar reports rendering, uploading, verification, registration and cooldown separately; temporary GitHub throttling is handled automatically. Animated files use the first frame. PDF pages are rendered locally; original PDFs are never sent to storage. Unsupported formats and oversized pages are reported rather than skipped.

2. Edit comics & chapters

Edit metadata, reorder chapters and pages, split a chapter at any page, or merge adjacent chapters. Changes to a published comic become visible only after Save.
